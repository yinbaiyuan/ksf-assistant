# 飞书实验台 · Vue 3

独立开发子项目，人工浏览和测试 KSFAssistant 飞书服务。它不是飞书服务实现，不取代桌面应用，也不会自动启动应用、申请权限或发送测试消息。

## 启动

需要 Node.js 22+、npm，以及包含当前原生飞书客户端的 KSFAssistant 安装包。先正常打开 KSFAssistant，再从仓库根目录执行：

```bash
cd FeishuLab
npm ci
npm run dev
```

打开 `http://127.0.0.1:4318`。必须使用这个地址，不使用 `localhost` 或局域网 IP。关闭终端中的进程即可停止测试台，不会退出桌面应用。

也可以运行编译后的页面：

```bash
npm run build
npm start
```

macOS 默认从当前用户 `~/Applications/KSFAssistant.app` 中选择本机架构的原生客户端。安装在其他位置时设置 `FEISHU_LAB_CLIENT` 为安装包中的可执行普通文件绝对路径；不接受符号链接。Windows 同样通过此变量指定安装包中的 `ksf-assistant-feishu-bridge.exe`，保持原生当前用户 Named Pipe 链路，不运行 WSL 客户端。

```powershell
$env:FEISHU_LAB_CLIENT = 'C:\实际安装目录\resources\runtime\feishu-bridge\windows-x64\ksf-assistant-feishu-bridge.exe'
npm run dev
```

端口冲突时设置 `FEISHU_LAB_PORT`（1024–65535），然后使用对应的 `127.0.0.1` 地址。环境变量只指定客户端路径和端口，不能指定任意命令、脚本或飞书 API。

## 人工测试流程

1. **能力实验**：目录来自安装版客户端，不硬编码数量。按业务域、身份、风险、治理或关键词筛选，收藏常用能力；展开契约查看输入、scope、作用、队列及核验声明。
2. **身份与权限**：点“核验当前授权”，分别看机器人、用户、应用权限与 OAuth，检索缺项或额外 scope。身份在线不等于所有能力可用，也不要为了变绿盲目扩权。
3. **参数校验**：使用表单或 JSON；输入文件通过附件控件显式上传。校验仅做结构检查，不产生业务执行，也不是平台权限检查。
4. **执行**：勾选执行意图后提交。直接放行可能立即产生真实副作用；逐次确认返回原 Operation，核对摘要后经页内二次确认执行或取消。禁止策略不能靠参数校验绕过。
5. **核验**：查询原操作状态、工作箱结果或审计。超时或结果未知不代表失败，不自动重试。原 Operation 未返回时，先到服务诊断/审计核对，不能通过再次发送来验证。
6. **治理策略**：显示风险默认及能力覆盖；编辑时展示前后差异，二次确认才保存，携带原 revision 防止覆盖其他客户端修改。刷新失败保留草稿；版本改变后显式将本次差异合并到最新版本，再重新核对提交。放弃草稿不会改变服务策略。
7. **服务诊断 / 运行记录**：检查服务能力状态、固定事件目录与有限事件查询、目标别名及任务关联；保留原结果 ID，可导出不含正文与目标的会话摘要。

“逐次确认”指本机 Operation 治理，不是飞书 Approval 业务。**平台授权、治理规则、运行开关、资源可见性是不同门禁**；测试台不绕过其中任何一项。

## 限制与隐私

- 主应用未运行时仅静态目录可用；业务明确失败，没有离线队列或自动唤醒。
- 浏览器不接受服务器文件路径、输出目录、原始命令、任意 OpenAPI 或脚本。需要本地输出文件的能力（例如 `docs.resource.read` 的必填 `output`）只能查看契约，执行应使用原生客户端；其他能力按服务规则处理。
- 输入与附件合计 4 MiB；附件通过私有临时文件交给原生客户端，由客户端转换为受限字节传输。正常结束、失败和正常关闭时清理；强制杀进程可能留下当前用户私有临时目录。
- 目录目前不暴露枚举值及全部范围约束；表单显示类型和必填项，最终仍由服务严格校验。并非每个能力都已在真实租户执行过。
- 每进程最多 4 个请求并发、单次客户端等待 90 秒、输出 16 MiB。结构校验凭据有效 2 分钟、一次性使用。相同请求标识不重复执行，超时不自动重放；进程重启不恢复这些内存记录。
- 附件替换立即清除旧附件和校验凭据，读取完成前不能执行。重复点击当前表单/JSON 标签不会覆盖编辑内容。网络响应丢失明确显示结果未知，不沿用上次成功结果。
- 最近 100 条会话记录、12 个参数用例、收藏仅驻留浏览器内存。刷新页面会清除，不保存到 localStorage。切换能力不会取消远端请求；待确认操作可在运行记录继续处理。
- 页面可按用户操作显示业务正文、身份和结果，区别于桌面的脱敏投影。仅在可信的本机浏览器使用，不共享页面、截图或未脱敏结果。不把真实凭据粘贴到参数中。
- 凭据仍由飞书服务持有，适配器不读取 Keychain、DPAPI 或生产业务文件。没有遥测、外部字体、CDN、CORS 或公网监听。只绑定回环地址并不等于防御已攻陷的同用户进程。

## 测试与目录

```bash
npm run check
npm run build
node test/fixture-server.mjs
```

夹具地址 `http://127.0.0.1:4319` 使用真实静态目录和内存假策略/操作，**没有真实飞书调用**。用于检查直通、禁止、逐次确认、策略差异、用例加载、权限缺项以及桌面/窄屏布局。不要把夹具成功当作线上权限验证。

| 路径 | 职责 |
| --- | --- |
| `src/` | Vue 页面、表单、策略差异、确认及结果展示 |
| `shared/model.mjs` | 治理决策展示、筛选、字段转换及脱敏摘要 |
| `server/app.mjs` | 同源会话、请求白名单、输入限制、执行去重及策略复核 |
| `server/bridge.mjs` | 固定原生客户端进程、私有 stdin、取消、输出限制及临时输入 |
| `server/main.mjs` | 回环监听、开发中间件、生产静态页面及停止处理 |
| `test/` | 隔离 HTTP / 假客户端进程回归与浏览器夹具 |

架构与验收范围见 [PRD](../docs/prd/feishu-lab.md) 和 [验证记录](../docs/architecture/feishu-lab-validation.md)。Windows 本机进程/Named Pipe 和真实租户的写入应另行人工验收，不用本机假传输结果替代。
