# 飞书人工测试台

## 目标

`FeishuLab` 是 Vue 3 子项目，用于人工浏览、验证和执行现有飞书服务已发布的能力。它不是新飞书服务，不持有凭据，不启动应用、daemon 或第二个事件消费者。

## 操作面

- 能力目录：读取安装版 CLI 的公开目录；按业务域、身份、风险、治理决策和关键词筛选，查看输入字段、作用、队列、前置核验和复读声明。数量实时推导。
- 请求工作区：按字段填写或编辑 JSON，显式上传文件，先做无副作用的结构校验，再手动执行；结构校验不等于授权通过或真实预检完成。
- 治理：本机 `allowed / disabled / confirm_each` 显示为直接放行、禁止、逐次确认。能力覆盖优先于风险默认；未知策略不能推断为放行。治理编辑必须明确提交并携带 revision，不自动改开关或申请 scope。
- 权限：分开展示 bot、user、应用权限和 OAuth；未知或平台未暴露的 bot scope 不能宣称逐项齐全。缺项、额外权限均可检索。
- 执行与确认：执行可能立即产生副作用；需逐次确认时保留原 Operation 和 challenge，用户明确确认或取消。状态查询不重放；结果未知要求先核对。
- 诊断：服务快照、基础健康、队列、固定事件目录与有限事件记录、目标别名、任务关联只读视图。不自动扫描聊天或同步通讯录。
- 记录：本次会话请求结果、Operation 查询、三箱历史和有限审计查询。刷新页面不自动重跑或恢复审批。导出只包含脱敏运行摘要，不导出正文、目标或 challenge。

## 本机边界

浏览器不能直接访问 Unix Socket / Named Pipe，因此开发工具提供仅监听 `127.0.0.1` 的同源薄适配器。它仅调用安装版原生客户端的固定命令，再进入 Core 的当前用户网关；不开放任意 CLI 参数、SDK、OpenAPI、脚本或业务文件读写。它是显式启动的开发工具，不加入应用生产进程树或业务 HTTP 接口。

所有 API 检查 Host、Origin；会话握手要求专用请求头，后续请求验证会话令牌。不启用 CORS，不记录输入正文。输入/输出有体积和并发上限，临时上传只含用户主动选择的文件，在调用结束、失败或正常关闭时清理；强制杀进程可能留下私有临时目录。浏览器不可指定服务器文件路径或下载目录；要求必填输出文件的能力明确标为需原生客户端执行，不伪装成可在浏览器完整测试。真实操作失败不自动重试；服务未运行时目录仍可读取，业务明确不可用。

## 验收

假 CLI 覆盖直通、禁止、逐次确认、撤权/版本变化、过期校验、超时未知、重复提交、非法命令/路径、跨站请求、文件限制和清理。Vue 构建、逻辑测试与浏览器桌面/窄屏操作验证必须通过。真实服务只做读取烟测，真实写入由人工自行选择目标和内容，不能为验收自动发送消息或扩大授权。
