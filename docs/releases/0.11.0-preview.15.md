# KSFAssistant 0.11.0-preview.15

`0.11.0-preview.15` 为旧版本缺少 `flowId` 的成功连接回执补充保守迁移：

- 根 `create_app` 或 `start_auth` 仍为未决、且 10 分钟会话期限内恰好存在一个匹配类型的 `completed/verified` 后续核验时，将根回执持久收口为成功。
- 迁移从后续核验继承本地 `flowId`；多个不同 flow 候选、超时核验、错误动作或未核验结果一律保持未决，不猜测对应关系。
- 初始化迁移同时处理“后续已核验 finish”和“后续已核验 logout”，因此升级后旧成功连接不会继续显示待核实，旧注销流程也不会再禁用新扫码。

新流程继续使用 `0.11.0-preview.14` 引入的同步 flow 捕获。本版本不改变受管 `lark-cli`，其版本仍为 `1.0.93-ksfassistant.1`。
