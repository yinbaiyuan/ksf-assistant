# KSFAssistant 0.11.0-preview.4

2026-09-08，首个测试里程碑。Git 标签：`v0.11.0-preview.4`。

## 主要改动

- 收敛飞书应用配置、扫码登录、权限检查、注销及恢复流程，配置与连接状态由 Go Core 统一管理。
- 完善飞书消息、任务卡片、续聊和状态同步；空回复不再显示成功，Codex 运行程序优先选用桌面应用自带版本，保留显式配置和独立 CLI 兜底。
- 修正本机 Token 统计，计入子 Agent 的独立消耗，并排除复制历史和重复请求造成的重复计数。
- 完善随包飞书 Skills 的适配、安装、所有权检查与回退，统一使用受管命令入口。
- 简化 macOS 用户身份写操作批准弹框，突出动作、对象、身份和完整内容预览，保留详情与明确取消路径。

## 验证范围

- Go 全量测试、静态检查及相关并发回归；Swift 与 Windows Node 测试。
- macOS、Windows 各两种架构的 Core 构建；macOS universal2 应用构建和签名验证。
- macOS 本机运行验证，以及用户确认飞书消息进入 Codex 后可正常响应。

这是测试版本。Windows 实机验收、公开发布、公证和远端标签推送不包含在本次里程碑中。
