# KSFAssistant 0.11.0-preview.8

`0.11.0-preview.8` 修复彻底注销后首次点击“扫码连接飞书”被锁成回执待核实的问题：

- 固定版本 `lark-cli` 首次冷启动的瞬时健康检查失败不再缓存五分钟，下一次读取或操作会重新核验。
- Bridge 明确区分“官方创建进程尚未启动”和“进程已启动但远端结果未知”；前者显示为可重试的明确失败，不再禁止重复执行。
- 对旧版本遗留的 `create_app` 未核实回执，仅在确认从未生成持久执行租约且没有后续注销时解除锁定；任何可能已经提交到飞书的请求仍保持禁止重放。
- 增加 CLI 瞬时失败恢复、创建提交边界、RPC 错误分类及旧回执安全收敛测试。

本版本继续使用受管 `lark-cli 1.0.93-ksfassistant.1`；上游源码与补丁集合未变化。
