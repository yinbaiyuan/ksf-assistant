# CodexAssistant 0.6.0-internal.1

This internal preview adds explicit, temporary continuation of one local Codex task through an authorized Feishu direct message.

- A task-row control creates or releases an eight-hour `codex-feishu-task-link-v1` connection.
- Replies continue the exact local Codex thread; desktop and Feishu remain available with one serialized turn and at most one queued Feishu message.
- One progress card receives throttled phase updates, structured non-secret user questions, final output and differentiated failures.
- The bridge owns private thread/message mappings, redaction, inbound authorization, expiry and the `caffeinate -i` wake assertion.
- Group messages, attachments, remote command/file approvals, sensitive MCP elicitation and automatic linking remain unsupported.

The Mac must stay powered, online and running the compatible Feishu Bridge. This build is prepared only; installation and publication require separate authorization.
