# KSFAssistant 0.11.0-preview.13

`0.11.0-preview.13` 在 `0.11.0-preview.12` 的登录回执生命周期修复上补齐初始化迁移门禁：

- Core 初始化时、启动任何受管飞书进程之前，自动扫描旧版本遗留的连接流程回执。
- 如果已核验的后续注销晚于未决的应用接入或用户授权流程，将旧流程持久标记为 `cancelled_by_logout`，并清除应用、身份、权限、上下文和流程标识。
- 因此用户无需先进入飞书设置页或手动刷新，重新启动 KSFAssistant 后新的“扫码连接飞书”即可使用。
- 初始化 RPC 回归测试直接覆盖旧 `create_app=pending` 与较晚 `logout=completed/verified` 的真实时间顺序。

本版本不改变受管 `lark-cli`，其版本仍为 `1.0.93-ksfassistant.1`。
