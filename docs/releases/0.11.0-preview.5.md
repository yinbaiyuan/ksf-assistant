# KSFAssistant 0.11.0-preview.5

2026-09-10，本地预览里程碑，尚未发布。

## 变化

- 飞书应用创建或选择完成后，优先使用首次扫码返回的本人 `open_id` 自动绑定，不再把基础消息和卡片连接建立在用户 OAuth 之上。
- 用户身份能力改为按实际命令缺失 scope 渐进授权；基础机器人能力只校验最小应用权限。
- 注销改为 fail-closed 的本地彻底清理，并隔离 KSFAssistant 使用的 lark-cli profile、凭据与专属主密钥。
- KSFAssistant 宿主、Shared Core、飞书服务、任务 CLI 和受管命令客户端统一使用同一个产品版本，不再分别管理组件版本。
- 受管 lark-cli 将上游版本与 KSFAssistant 补丁合成 `1.0.93-ksfassistant.1`；补丁只保留哈希溯源，不再单独编号。

## 版本来源

- 产品版本：`version.json`
- 受管 lark-cli 版本：`runtime/lark-cli-runtime.json`
- 协议与持久化 schema：由各自兼容性契约独立管理
