# KSFAssistant 0.11.0-preview.16

`0.11.0-preview.16` 修正飞书基础连接与可选用户 OAuth 在设置页上的语义混淆：

- 以机器人身份运作的消息、卡片和任务控制已正常时，未做用户 OAuth 改为显示“用户能力授权：按需授权（不影响消息和卡片）”，不再暗示基础连接异常。
- macOS 和 Windows 不再根据“用户 OAuth 缺失”自行推导并常驻显示“补充本人授权”；只有 Core 为首次扫码缺少本人标识，或某项用户能力生成了精确授权请求时，才开放对应按钮。
- 基础连接、本人操作者绑定和用户能力授权仍保持三条独立证据链，本次只收敛展示和操作入口，不放宽授权校验。

受管 `lark-cli` 未变，版本仍为 `1.0.93-ksfassistant.1`。
