# Codex Usage Bar 0.4.0-internal.1

首个 KSF 团队内部预览版。

## 主要变化

- 使用 `com.ksf.codexusagebar` 独立身份，不读取个人版设置、Keychain 或 Application Support 数据。
- 首次启动显式选择并验证 KSF，登录启动和额度通知默认关闭。
- Token 历史使用 `codex-local-token-history-v2`，保留但不读取旧 v1 文件。
- 保留额度、Token、桌面任务、KSF 工作台和微信扫码连接全部能力。
- 同时提供 Apple Silicon 与 Intel 的 universal2 应用。
- 构建和安装脚本不再依赖个人路径或个人签名证书。

## 安装提醒

该 ZIP 使用 ad-hoc 签名且未经 Apple 公证，仅供知情的团队内部成员使用。下载后先核对 `SHA256SUMS`；若 Gatekeeper 阻止首次启动，请在 Finder 中右键应用并选择“打开”。

## 已知限制

- Codex Desktop IPC 是私有兼容层，Codex 升级后可能需要适配。
- 当前没有自动更新、Developer ID 公证或 Mac App Store 发行。
- Intel 架构已完成交叉编译和 universal2 校验；稳定支持仍以 Intel 真机烟测为准。
