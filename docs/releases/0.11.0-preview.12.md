# KSFAssistant 0.11.0-preview.12

`0.11.0-preview.12` 修复成功连接飞书并注销后，历史扫码回执仍会禁用下一次“扫码连接飞书”的问题：

- 完成 `finish_app` 或 `finish_auth` 核验时，按不可伪造的本地 `flowId` 精确终结最初的 `create_app` 或 `start_auth` 回执，防止已完成流程继续显示为待核实。
- “注销并清除飞书”会终结此前所有未决的应用接入和用户授权流程，将其标记为已核验、已取消且不可重放；消息发送等非连接写操作仍保持原有结果语义。
- 对旧版本已经形成的“连接成功 → 注销成功 → 原扫码仍 pending”记录在飞书配置刷新时进行持久化迁移，清除应用、身份、权限和流程标识，并恢复新的扫码入口；Core 初始化前的自动迁移由后续 `0.11.0-preview.13` 补齐。
- 新增真实时间顺序回归、跨流程精确收口、注销清理和非连接写操作隔离测试。

本版本不改变受管 `lark-cli`，其版本仍为 `1.0.93-ksfassistant.1`。
