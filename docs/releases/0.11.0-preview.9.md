# KSFAssistant 0.11.0-preview.9

`0.11.0-preview.9` 完成扫码连接失败的提交边界修复：

- 固定版本 `lark-cli` 的瞬时本地健康检查失败不再缓存五分钟。
- Bridge 以“飞书验证页面是否已交付给用户”作为远端创建边界：在二维码或链接出现前失败，明确返回可重试失败；二维码出现后的不确定结果继续禁止重放。
- Core 将前一种情况显示为“扫码流程尚未启动”，不会再把用户锁在“原请求尚待核实”。
- 删除以共享零字节执行锁推断单次请求结果的方案；该锁不是请求级证据，不能用于自动改写历史回执。
- 增加 CLI 瞬时失败恢复、进程启动前失败、验证页面出现前失败和 RPC 错误分类测试。

本版本继续使用受管 `lark-cli 1.0.93-ksfassistant.1`；上游源码与补丁集合未变化。
