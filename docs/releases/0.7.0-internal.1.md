# CodexAssistant 0.7.0-internal.1

This internal preview upgrades the Feishu task link into full control of one explicitly connected Codex task.

- The bridge protocol remains `codex-feishu-task-link-v1` and moves to response version 2 with split link/turn state, feature readiness and a 24-hour inactivity lease.
- Feishu can observe and steer the current desktop turn, continue later turns with full local permissions, answer ordinary questions, send ordinary attachments and stop the current turn.
- Task detail shows the authorized alias, controller, state, remaining lease and last synchronization time without exposing private identifiers.
- Release closes only the Feishu channel; a local turn continues and cannot resurrect the released link.

The build is ad-hoc signed, not notarized, and intended for informed internal testing. Real Feishu task control still requires an explicitly selected task and authorized direct-message alias.
