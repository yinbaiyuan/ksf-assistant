# Codex Usage Bar 0.5.0-internal.1

待发布的 KSF 团队内部预览版。

## 主要变化

- 删除微信扫码、Keychain、入站轮询与本机命令队列能力。
- 新增飞书桥工程发现、手动选择、只读状态与脱敏目标别名。
- 测试消息仅由用户点击发送固定可见正文，并继续经过飞书桥 outbox、安全开关、去重、脱敏与审计。
- 新版首次启动精确清理同 Bundle ID 下的旧微信 Keychain 项和 `wechat-state-v1.enc`；不触碰其他服务或文件。
- Usage Bar 不保存飞书凭据、真实目标 ID、目录缓存、消息历史或入站内容。

## 安装提醒

该 ZIP 使用 ad-hoc 签名且未经 Apple 公证，仅供知情的团队内部成员使用。飞书能力还要求本机安装 Node.js，并准备兼容的 `feishu-bot-bridge` 工程与安全目标别名。

## 已知限制

- 本版只支持手动测试发送，不包含自动额度提醒、任务完成通知或飞书入站命令。
- 飞书桥停止、出站关闭或处于 dry-run 时，Usage Bar 会禁用测试发送；不会替用户修改桥配置或自动启动服务。
- Codex Desktop IPC 是私有兼容层，Codex 升级后可能需要适配。
