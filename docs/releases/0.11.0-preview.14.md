# KSFAssistant 0.11.0-preview.14

`0.11.0-preview.14` 补齐扫码连接根回执与后续核验回执的精确关联：

- `create_app` 或 `start_auth` 已提交并进入等待状态时，Core 立即从飞书桥同步读取当前本地 flow，并校验 ID、类型和状态后写入私有回执。
- 不再依赖动作完成后尚未刷新的桌面快照获取 `flowId`；若同步核验失败，操作保持“结果未知”且禁止重放。
- `finish_app` 和 `finish_auth` 现在可以按同一 `flowId` 精确终结根回执；不同 flow、不同动作或消息写操作不会被误判为完成。
- 回归测试覆盖完整 `create_app → pending receipt → finish_app → completed root receipt` 链路。

本版本继承 `0.11.0-preview.13` 的初始化期旧回执迁移，不改变受管 `lark-cli`；其版本仍为 `1.0.93-ksfassistant.1`。
