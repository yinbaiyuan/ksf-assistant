# 公开源码导出

公开仓库必须从审计通过的工作树生成干净快照，不能复制当前私有仓库的 `.git`、remote、refs、reflog、对象库或历史提交。

1. 在私有分支完成测试、许可证、秘密扫描和发布卫生检查。
2. 使用 `scripts/export-public-source.sh <空目录>` 导出 Git 跟踪文件。
3. 在导出目录再次运行发布卫生与秘密扫描，并人工核对来源清单。
4. 仅在用户明确决定公开托管平台后，在导出目录初始化新仓库并创建单一首提交。
5. 单独配置公开 remote；不得从私有仓库复制 remote 配置或对象。

导出脚本只创建源码快照与清单，不初始化 Git、不联网、不推送也不发布。
